#PDP

A responsive e-commerce product detail page built with React, TypeScript, and Vite.

## Features

- Product image display
- Color & size variant selection
- Inventory check
- Quantity adjustment
- Add to cart
- Cart counter

## Tech Stack

- React 18
- TypeScript
- Vite

## Prerequisites

- Node.js v18+
- npm

1. Install dependencies
   
   ```bash
   npm install
   ```
2. Start development server
   
   ```
   npm run dev
   ```
